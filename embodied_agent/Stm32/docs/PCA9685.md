# Sterownik PCA9685 - Dokumentacja

## Opis
Implementacja sterownika PWM PCA9685 (16 kanałów 12-bitowego PWM) dla STM32F042K6.

## Konfiguracja sprzętowa

### Połączenia I2C
- **PF1** → I2C1_SCL (SCL PCA9685)
- **PF0** → I2C1_SDA (SDA PCA9685)

### Zasilanie PCA9685
- **VCC** → 3.3V lub 5V (zależnie od wersji modułu)
- **GND** → GND
- **V+** → Zasilanie zewnętrzne dla serw (4.8-6V)

### Adres I2C
Domyślny adres: **0x40** (7-bit)

## API

### Inicjalizacja
```c
// Inicjalizacja I2C
I2C_Init();

// Inicjalizacja PCA9685
PCA9685_Init(&hi2c1);
```

### Ustawianie częstotliwości PWM
```c
// Typowo 50Hz dla serw
PCA9685_SetPWMFreq(&hi2c1, 50.0f);
```

### Sterowanie serwem - kąt (0-180°)
```c
// Ustaw serwo na kanale 0 na 90 stopni
PCA9685_SetServoAngle(&hi2c1, 0, 90);

// Pełny zakres
PCA9685_SetServoAngle(&hi2c1, 0, 0);    // 0°
PCA9685_SetServoAngle(&hi2c1, 0, 90);   // 90°
PCA9685_SetServoAngle(&hi2c1, 0, 180);  // 180°
```

### Sterowanie serwem - impuls (μs)
```c
// Ustaw długość impulsu w mikrosekundach
PCA9685_SetServoPulse(&hi2c1, 0, 1500); // Środkowa pozycja (1.5ms)

// Typowe wartości:
// 500-1000μs  → 0°
// 1500μs      → 90°
// 2000-2500μs → 180°
```

### Bezpośrednie sterowanie PWM
```c
// Wartości 0-4095 (12-bit)
PCA9685_SetPWM(&hi2c1, channel, on_value, off_value);

// Przykład: 50% duty cycle
PCA9685_SetPWM(&hi2c1, 0, 0, 2048);
```

## Przykłady użycia

### Przykład 1: Sterowanie pojedynczym serwem
```c
// Ustaw serwo w pozycji środkowej
PCA9685_SetServoAngle(&hi2c1, 0, 90);
HAL_Delay(1000);

// Ruch do pozycji maksymalnej
PCA9685_SetServoAngle(&hi2c1, 0, 180);
HAL_Delay(1000);

// Powrót do pozycji minimalnej
PCA9685_SetServoAngle(&hi2c1, 0, 0);
```

### Przykład 2: Sterowanie wieloma serwami
```c
// Ustaw różne pozycje na różnych kanałach
PCA9685_SetServoAngle(&hi2c1, 0, 45);   // Kanał 0 → 45°
PCA9685_SetServoAngle(&hi2c1, 1, 90);   // Kanał 1 → 90°
PCA9685_SetServoAngle(&hi2c1, 2, 135);  // Kanał 2 → 135°
```

### Przykład 3: Płynne przesuwanie
```c
// Płynny ruch od 0 do 180 stopni
for (uint8_t angle = 0; angle <= 180; angle += 5)
{
    PCA9685_SetServoAngle(&hi2c1, 0, angle);
    HAL_Delay(50);  // 50ms opóźnienia między krokami
}
```

## Kalibracja serw

Domyślne wartości impulsów mogą wymagać dostosowania dla konkretnego serwa:

```c
// Dla serw z niestandardowym zakresem:
// Minimalny impuls (0°)
PCA9685_SetServoPulse(&hi2c1, 0, 600);

// Maksymalny impuls (180°)
PCA9685_SetServoPulse(&hi2c1, 0, 2400);
```

## Rozwiązywanie problemów

### Serwo nie reaguje
1. Sprawdź połączenia I2C (SCL/SDA)
2. Sprawdź zasilanie V+ (osobne dla serw)
3. Sprawdź adres I2C (domyślnie 0x40)
4. Sprawdź czy PCA9685 odpowiada:
   ```c
   HAL_StatusTypeDef status = HAL_I2C_IsDeviceReady(&hi2c1, PCA9685_ADDRESS << 1, 3, 100);
   if (status != HAL_OK) {
       // PCA9685 nie odpowiada
   }
   ```

### Serwo drży
1. Upewnij się, że zasilanie V+ jest stabilne i wystarczające
2. Dodaj kondensatory wygładzające (100-470μF) przy zasilaniu
3. Sprawdź czy częstotliwość PWM wynosi 50Hz

### Nieprawidłowy zakres ruchu
1. Kalibruj wartości impulsów dla konkretnego serwa
2. Typowy zakres: 500-2500μs, ale może się różnić
3. Użyj `PCA9685_SetServoPulse()` do precyzyjnej kontroli

## Parametry techniczne

- **Kanały**: 16 wyjść PWM
- **Rozdzielczość**: 12-bit (4096 kroków)
- **Częstotliwość PWM**: 24Hz - 1526Hz (typowo 50Hz dla serw)
- **Interfejs**: I2C (Fast mode do 400kHz)
- **Napięcie zasilania**: 2.3V - 5.5V (logika)
- **Napięcie V+**: Do 6V (dla serw)
